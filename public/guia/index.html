GUIA RÁPIDO

Seu primeiro macro.

Comece com dados de exemplo e confira cada ação antes de executar o fluxo inteiro.

  1. Obtenha o aplicativo

    Se você ainda precisa de uma cópia do Automatizador PRO para Windows, solicite acesso ao suporte.

  2. Crie um macro de teste

    No editor, crie um macro e adicione uma ação pelo catálogo pesquisável. Para testar digitação, abra o Bloco de Notas e use uma frase fictícia.

  3. Selecione uma planilha

    Use uma cópia de exemplo em XLSX, CSV ou XLS. Selecione a aba, quando disponível, escolha as linhas e associe as colunas às variáveis. Defina o comportamento para valores vazios.

  4. Teste uma ação

    Use o teste do editor em uma única ação. Confira a janela de destino e o valor inserido. Para OCR, configure o Tesseract e o idioma e confira a região selecionada.

  5. Execute e acompanhe

    Quando o macro de teste estiver pronto, use F9 para executar e F10 para parar. Esses são os atalhos padrão. O HUD permite pausar, retomar e inspecionar variáveis. Para executar o macro real, confira novamente a origem e o destino dos dados.

  6. Ative o Stream Deck

    Abra Configurações → Celular, autorize o domínio do site e ligue o painel. Na mesma rede, conecte nesta página do Stream Deck com o endereço e o PIN mostrados no app.
