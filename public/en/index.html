FAQ

Common questions.

Does my PC need to stay on?

Yes. Windows and Automatizador PRO must remain running while the macro executes.

Which spreadsheet formats work?

XLSX, CSV and legacy XLS. You can select rows, reuse values and match data by key.

Why won't Stream Deck connect?

Check the authorized website domain, the local address, the PIN and the browser's local network permission. Guest networks can isolate devices.

Can I read a scanned PDF?

PDF extraction reads an existing text layer. Use Tesseract OCR for scans, and check the output before using it.

How do I report a problem?

Include your app and Windows versions, the action that failed, and steps to reproduce it. Keep passwords, PINs and customer data private.
