Documentation

A reference for building, testing and running Windows macros.

Board and subflows · Vision and counting · Copilot, AI actions and dictation · Telegram · Editor · Variables · Data · Actions · Stream Deck · Troubleshooting

Editor and execution

Open the sidebar with ☰ to search macros, seven per page. The toolbar contains New macro, Import, Settings and Help. Glass keeps the window opaque and uses frosted buttons. Organize actions with groups, conditions and repeat blocks. Test individual actions, add comments, reorder steps and turn off steps you want to skip. Use Run and Stop in the toolbar or their displayed shortcuts. The floating monitor shows active time, completed cycles and the current step.

Variables and formulas

Use ${Name} to insert a value. The { } button lists available system values, spreadsheet columns and outputs from other actions. Use Set variable to save a value and Format variable for transformations, regex, dates or calculations.

Expressions use the function names supported by the desktop app, for example numero(${Amount}) > 0.

Spreadsheets and documents

Import XLSX, CSV or XLS. Select the rows you want to process and use column names as variables. Join tables by a matching key. Read searchable PDF text directly. For scanned images or screen regions, configure Tesseract and verify the OCR result.

Text, HTTP and visual actions

  • Text blocks: create pages, drag the tabs to reorder them, and choose sequential or random selection. Each page can contain variables.
  • HTTP requests: choose the method and URL, optionally enter JSON headers and a request body, then save the response status, body or JSON fields. A mapping can use rows.0.name=customer.
  • Detect image: choose an image and optional region. Select a click type and an anchor, move the pointer only, or leave the pointer untouched.

Stream Deck

On Windows, authorize the site's HTTPS domain in Settings → Mobile and start the panel. Both devices must be on the same network. Enter the PC address, port and PIN in Stream Deck. Use the PC's network address when connecting from a phone.

Troubleshooting

  • For a failed image match, check the capture region, monitor scaling and whether the target is visible.
  • For empty variables, confirm the column or output exists and was created before the current step.
  • For connection errors, check the authorized domain and browser permission for local network access.

Board and subflows

Switch between List and Board next to the macro name. Zoom with the wheel, pan with the middle mouse button, and use Fit to see the entire flow. Create a subflow through + Flow and call it with Run subflow, for example inside an image condition. Connections represent list structure. Moving a node changes its layout; editable wires and parallel branches are not available.

Vision and counting

Upload a reference or paste a crop with Ctrl+V. Restrict the search region and test the match threshold. Count Images accepts the entire screen, a monitor or a region and stores an integer, including zero. Use ${qtd_encontrada} > 0 in a variable condition or pass the variable to a repeat block.

Copilot, AI actions and dictation

In Settings → Copilot, select Gemini, Groq or OpenRouter, enter your API key and fetch models. Review suggestions before applying them. The provider receives the conversation and a summary of the workflow structure. Process with AI also sends the instruction and any variable values it uses, then stores the reply. The _erro output helps handle failures when continuation is enabled. Select and test an input in Settings → Microphone before using Dictate. Transcription uses Windows speech recognition.

Telegram

In Settings → Telegram, enter the bot token and private chat ID. Use /exec Macro name to start an existing macro. An approval action waits up to two minutes. Error screenshots require explicit opt-in in Settings.
