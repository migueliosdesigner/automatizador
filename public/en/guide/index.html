Quick start

Build and test your first Windows macro.

  1. Open Automatizador PRO and create a new automation.
  2. Select New action and add a step such as Wait or Insert text.
  3. Choose the repeat count and speed in the toolbar. The infinity control repeats until you stop it. Spreadsheet macros follow the selected rows.
  4. Test individual steps on a safe target, then choose Run. The toolbar displays your configured shortcuts.

Editor and action catalog

Control it from your phone

In Settings → Mobile, authorize the website domain, optionally name the PC, and start the panel. Pair through Stream Deck on the same network.
